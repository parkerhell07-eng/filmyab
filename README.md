# 🎬 فیلم‌یاب — FilmYab

**اسم فیلم را از روی کلیپ اینستاگرام پیدا کن.**

لینک یک تیزر فیلم یا کلیپی از فیلمی که می‌بینی ولی اسمش را نمی‌دانی را وارد کن؛ فیلم‌یاب با یک خط‌لولهٔ هوش مصنوعی اختصاصی، اسم دقیق فیلم را به‌همراه درصد اطمینان، پوستر، کارگردان و گزینه‌های محتمل دیگر برمی‌گرداند.

> این ریپو شامل **سه بخش** است: بک‌اند (Next.js API) + وب‌اپ فارسی (PWA) + **اپ اندروید نیتیو (Kotlin + Jetpack Compose)** با بیلد خودکار APK توسط GitHub Actions.

## 📱 نصب نسخه اندروید

آخرین APK را مستقیم دانلود کن:

**⟶ [دانلود FilmYab APK](https://github.com/parkerhell07-eng/filmyab/releases/latest/download/FilmYab-v1.0-debug.apk) ⟶**

یا از صفحهٔ [Releases](https://github.com/parkerhell07-eng/filmyab/releases) فایل موردنظر را انتخاب کن.

1. فایل APK را دانلود و اجرا کن (اجازه «نصب از منابع ناشناس» را بده).
2. لینک پست/ریلز اینستاگرام را وارد کن و «شناسایی فیلم» را بزن.
3. برای تحلیل کامل، در تب **تنظیمات** آدرس سرور بک‌اند را وارد کن (پیش‌فرض `http://10.0.2.2:3000` فقط داخل شبیه‌ساز اندروید کار می‌کند).

### دو حالت شناسایی در اپ

| حالت | شرح | پیش‌نیاز |
|---|---|---|
| **تحلیل کامل (سرور)** | استخراج ویدیو/کاور + تحلیل فریم‌ها با هوش مصنوعی بینایی + جستجوی وب + تطبیق هوشمند + پوستر | یک سرور بک‌اند فعال (تنظیم در تب تنظیمات) |
| **تحلیل سریع روی دستگاه** | اسکرپ مستقیم کپشن/هشتگ پست + استدلال مدل زبانی + لینک جستجوی گوگل — به‌صورت **خودکار** وقتی سرور در دسترس نباشد | هیچ |

حالت اسکرین‌شات (انتخاب تصویر از گالری) هم پشتیبانی می‌شود و برای پست‌هایی که اینستاگرام لینک‌شان را مسدود کرده، بهترین راه است.

## 🧠 الگوریتم شناسایی (خط‌لوله اختصاصی)

```
لینک اینستاگرام
   │
   ▼
۱. دریافت پست — زنجیرهٔ چندروشی: embed/captioned، ?__a=1 (X-IG-App-ID)، og: meta tags + رفع ریدایرکت /share/
   │
   ▼
۲. تحلیل صحنه — ویدیو → ffmpeg (فریم‌های کلیدی) → مدل بینایی (GLM-4.6V) → توصیف صحنه + متن روی تصویر
   │  (فالبک: تحلیل کاور تصویری)
   ▼
۳. جستجوی وب — ساخت کوئری‌های هوشمند از کپشن + هشتگ‌ها + توصیف صحنه
   │
   ▼
۴. تطبیق هوشمند — مدل زبانی با حالت thinking، نمره‌دهی اطمینان + نام فارسی + گزینه‌های جایگزین
   │
   ▼
۵. پوستر — جستجوی تصویر و انتخاب بهترین پوستر رسمی
   │
   ▼
نتیجه: اسم فیلم + سال + کارگردان + ژانر + ٪اطمینان + توضیح فارسی + گزینه‌های دیگر + منابع
```

## 🖥 اجرای بک‌اند

```bash
bun install
bun run db:push     # ساخت دیتابیس SQLite
bun run dev         # http://localhost:3000
```

وب‌اپ روی `/` اجرا می‌شود و همان خط‌لوله را با رابط فارسی ارائه می‌دهد. اپ اندروید به همین API وصل می‌شود:

- `POST /api/identify` — ورودی `{url}` یا `{imageBase64}` (+ `note` اختیاری) → پاسخ **SSE** با رویدادهای مرحله‌ای و نتیجهٔ نهایی
- `GET /api/history` — تاریخچه (۳۰ مورد آخر)
- `DELETE /api/history` — پاک‌سازی تاریخچه

> ⚠️ بک‌اند از `z-ai-web-dev-sdk` (مدل بینایی، جستجوی وب، جستجوی تصویر) استفاده می‌کند؛ برای اجرا روی سرور شخصی باید اعتبارنامه‌های SDK از طریق متغیرهای محیطی تنظیم شده باشند (در محیط ساخت این پروژه از قبل تنظیم است). برای اتصال گوشی به سرور محلی، آدرس LAN سیستم (مثل `http://192.168.1.10:3000`) را در تب تنظیمات اپ وارد کن.

## 🛠 بیلد دستی APK

```bash
cd android-app
gradle assembleDebug          # خروجی: app/build/outputs/apk/debug/app-debug.apk
```

(یا پروژهٔ `android-app` را در Android Studio باز کن.)

پوشهٔ `.github/workflows/android-build.yml` روی هر push به `android-app/**` به‌صورت خودکار هر دو APK (debug و release) را می‌سازد و در GitHub Release منتشر می‌کند.

## 📂 ساختار

```
├─ src/                     بک‌اند Next.js + وب‌اپ فارسی
│  ├─ app/api/identify/     خط‌لوله SSE شناسایی
│  ├─ app/api/history/      تاریخچه
│  └─ lib/                  اسکرپر اینستاگرام + موتور شناسایی
├─ android-app/             اپ اندروید نیتیو (Kotlin + Compose)
│  └─ app/src/main/java/com/filmyab/app/
│     ├─ data/              ApiClient (SSE)، اسکرپر روی دستگاه، موتور فالبک
│     └─ ui/                صفحات شناسایی / تاریخچه / تنظیمات
├─ prisma/schema.prisma     مدل دیتابیس
└─ .github/workflows/       بیلد خودکار APK
```
