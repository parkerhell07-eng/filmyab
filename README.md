# 🎬 فیلم‌یاب — FilmYab

**اسم فیلم را از روی کلیپ اینستاگرام پیدا کن.**

لینک یک تیزر فیلم یا کلیپی از فیلمی که می‌بینی ولی اسمش را نمی‌دانی را وارد کن؛ فیلم‌یاب با یک خط‌لولهٔ هوش مصنوعی اختصاصی، اسم دقیق فیلم را به‌همراه درصد اطمینان، پوستر، کارگردان و گزینه‌های محتمل دیگر برمی‌گرداند.

> این ریپو شامل **دو بخش** است: وب‌اپ فارسی (Next.js + PWA) + **اپ اندروید نیتیو (Kotlin + Jetpack Compose)** با موتور هوشمند کاملاً روی دستگاه و بیلد خودکار APK توسط GitHub Actions.

## 📱 نصب نسخه اندروید (v3)

آخرین APK را مستقیم دانلود کن:

**⟶ [دانلود FilmYab APK v3.0](https://github.com/parkerhell07-eng/filmyab/releases/latest/download/FilmYab-latest-debug.apk) ⟶**

یا از صفحهٔ [Releases](https://github.com/parkerhell07-eng/filmyab/releases) فایل موردنظر را انتخاب کن.

1. فایل APK را دانلود و اجرا کن (اجازه «نصب از منابع ناشناس» را بده).
2. تمام! فقط لینک ریلز را از اینستاگرام «کپی لینک» کن — برنامه خودش لینک را از کلیپ‌بورد می‌خواند و شناسایی را شروع می‌کند.
3. هیچ تنظیماتی وجود ندارد: **سرور حذف شده** و کل موتور هوشمند روی خود دستگاه اجرا می‌شود.
4. **آپدیت درون‌برنامه‌ای**: وقتی نسخه جدید منتشر شود، خودِ برنامه خبر می‌دهد، APK را دانلود می‌کند و نصب را شروع می‌کند — نیازی به مراجعه به گیت‌هاب نیست.

### ⚡ نکتهٔ فیلترشکن

برنامه به‌صورت خودکار وضعیت اتصال را چک می‌کند و نوار وضعیت نشان می‌دهد:
- 🟢 «اینستاگرام در دسترسه» → همه‌چیز خودکار کار می‌کند
- 🟡 «فیلترشکن را روشن کن» → اینستاگرام از اینترنت شما فیلتر است؛ با فیلترشکن روشن، شناسایی خودکار انجام می‌شود
- 🔴 «اینترنت در دسترس نیست»

### موتور هوشمند روی دستگاه (v3 — چندکانالهٔ موازی)

| کانال | شرح | اینترنت لازم؟ |
|---|---|---|
| متادیتای پست | ۴ روش اسکرپ موازی (crawler UA / embed / api / og) → کپشن، هشتگ، og-title، آدرس ویدیو و کاور | با فیلترشکن |
| فریم + OCR | دانلود ویدیو (سقف ۴۵ مگابایت — فایل ناقص هم قابل استفاده است) → ۷ فریم → خواندن متن روی تصویر (تیتراژ/زیرنویس/کارت عنوان) با ML Kit | — |
| جستجوی وب زنده | قوی‌ترین سیگنال‌های پست (og-title/OCR/هشتگ) → جستجوی واقعی Bing (با fallback به DDG) بدون کلید → نتایج واقعی وب که معمولاً اسم دقیق فیلم را دارند | بله |
| تحلیل هوشمند | هوش مصنوعی آنلاین رایگان (بدون کلید) همه شواهد را می‌بیند: کپشن + هشتگ + OCR + نتایج وب زنده → ۳ کاندید مرتب‌شده؛ مدیریت هوشمند سقف رایگان (۱ پاسخ/۳۰ ثانیه) با «پنجره خنک‌سازی» و حداکثر یک انتظار مؤدبانه — هرگز گیر نمی‌کند | بله |
| تأیید و مشخصات کامل | تأیید موازی کاندیدها در ویکی‌پدیا (انگلیسی + فارسی) + غنی‌سازی از **ویکی‌داده**: ژانر، بازیگران، کارگردان، سال، پوستر + خلاصه داستان فارسی | بله |
| امتیازدهی ترکیبی | الگوریتم اختصاصی: تطبیق og-title / هشتگ / OCR با نام کاندید + تأیید ویکی‌پدیا → ٪اطمینان صادقانه؛ پاس تلفیق LLM فقط وقتی امتیاز مرزی است | — |

## 🧠 الگوریتم شناسایی (خط‌لوله اختصاصی)

```
لینک اینستاگرام (خودکار از کلیپ‌بورد یا دستی)
   │
   ▼
۱. بررسی اتصال — چک خودکار اینستاگرام/اینترنت → وضعیت فیلترشکن
   │
   ▼
۲. خواندن پست — ۴ روش موازی روی دستگاه: صفحهٔ پست با UA موتور جستجو (og:title/og:description + آدرس mp4 امضاشده)،
   embed/captioned، ?__a=1 (X-IG-App-ID)، og: meta + رفع ریدایرکت /share/
   │
   ▼
۳. استخراج فریم — دانلود ویدیو به کش (سقف ۴۵MB؛ فایل ناقص هم استفاده می‌شود) → MediaMetadataRetriever → ۷ فریم پخش‌شده روی کل زمان
   │
   ▼
۴. متن روی تصویر — ML Kit OCR روی همه فریم‌ها → تیتراژ، زیرنویس، کارت عنوان (fallback: OCR روی کاور پست)
   │
   ▼
۵. تحلیل چندکانالهٔ موازی — **C1 قطعی:** og-title/هشتگ/کپشن/OCR → جستجوی موازی ویکی‌پدیا · **C2 وب زنده:** Bing/DDG بدون کلید روی قوی‌ترین سیگنال‌ها → نتایج واقعی وب · **C3 هوش مصنوعی رایگان:** همه شواهد + نتایج وب → کاندیدهای مرتب؛ اگر AI محدود بود، عنوان‌های وب به‌عنوان کاندید می‌آیند (و بعداً سخت تأیید می‌شوند)
   │
   ▼
۶. تأیید و غنی‌سازی موازی — ویکی‌پدیا REST (سال/کارگردان/پوستر/عنوان فارسی) + **ویکی‌داده** (ژانر P136، بازیگران P161، کارگردان P57) + خلاصه داستان فارسی؛ حداکثر ۳ کار موازی
   │
   ▼
۷. امتیازدهی اختصاصی — تطبیق نرمال‌شدهٔ نام با og-title/هشتگ/OCR (+۰٫۱ تا +۰٫۱۵) + تأیید فیلم بودن (+۰٫۲۵)؛ پاس تلفیق LLM فقط وقتی امتیاز < ۰٫۷۵ (با همان پنجرهٔ خنک‌سازی — بدون ۴۰۲ بیخود)
   │
   ▼
نتیجه: اسم فیلم (انگلیسی + فارسی) + سال + کارگردان + ژانر + بازیگران + خلاصه داستان + پوستر + ٪اطمینان + گزینه‌های دیگر + لینک ویکی‌پدیا
```

> نسخهٔ وب همان خط‌لوله را با هوش مصنوعی بینایی قوی‌تر (z-ai SDK) و جستجوی وب ارائه می‌دهد.

## 🖥 نسخه وب

```bash
bun install
bun run db:push     # ساخت دیتابیس SQLite
bun run dev         # http://localhost:3000
```

وب‌اپ روی `/` اجرا می‌شود و همان ایده را با مدل بینایی قدرتمندتر و جستجوی وب ارائه می‌دهد:

- `POST /api/identify` — ورودی `{url}` یا `{imageBase64}` → پاسخ **SSE** با رویدادهای مرحله‌ای و نتیجهٔ نهایی
- `GET /api/history` — تاریخچه (۳۰ مورد آخر)
- `DELETE /api/history` — پاک‌سازی تاریخچه

> اپ اندروید **به این سرور وابسته نیست** — همه‌چیز را خودش انجام می‌دهد. نسخهٔ وب فقط یک رابط جایگزین با توان بیشتری است.

## 🛠 بیلد دستی APK

```bash
cd android-app
gradle assembleDebug          # خروجی: app/build/outputs/apk/debug/app-debug.apk
```

(یا پروژهٔ `android-app` را در Android Studio باز کن.)

پوشهٔ `.github/workflows/android-build.yml` روی هر push به `android-app/**` به‌صورت خودکار هر دو APK (debug و release) را می‌سازد و در GitHub Release منتشر می‌کند.
