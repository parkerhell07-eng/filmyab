# 🎬 فیلم‌یاب — FilmYab

**اسم فیلم را از روی کلیپ اینستاگرام پیدا کن.**

لینک یک تیزر فیلم یا کلیپی از فیلمی که می‌بینی ولی اسمش را نمی‌دانی را وارد کن؛ فیلم‌یاب با یک خط‌لولهٔ هوش مصنوعی اختصاصی، اسم دقیق فیلم را به‌همراه درصد اطمینان، پوستر، کارگردان و گزینه‌های محتمل دیگر برمی‌گرداند.

> این ریپو شامل **دو بخش** است: وب‌اپ فارسی (Next.js + PWA) + **اپ اندروید نیتیو (Kotlin + Jetpack Compose)** با موتور هوشمند کاملاً روی دستگاه و بیلد خودکار APK توسط GitHub Actions.

3. هیچ تنظیماتی وجود ندارد: **سرور حذف شده** و کل موتور هوشمند روی خود دستگاه اجرا می‌شود.

### ⚡ نکتهٔ فیلترشکن

برنامه به‌صورت خودکار وضعیت اتصال را چک می‌کند و نوار وضعیت نشان می‌دهد:
- 🟢 «اینستاگرام در دسترسه» → همه‌چیز خودکار کار می‌کند
- 🟡 «فیلترشکن را روشن کن» → اینستاگرام از اینترنت شما فیلتر است؛ با فیلترشکن روشن، شناسایی خودکار انجام می‌شود
- 🔴 «اینترنت در دسترس نیست»

### موتور هوشمند روی دستگاه

| کانال | شرح | اینترنت لازم؟ |
|---|---|---|
| متادیتای پست | ۴ روش اسکرپ موازی (crawler UA / embed / api / og) → کپشن، هشتگ، og-title، آدرس ویدیو و کاور | با فیلترشکن |
| فریم + OCR | دانلود ویدیو → ۳ فریم نمونه‌گیری‌شده → خواندن متن روی تصویر (تیتراژ/زیرنویس) با ML Kit (مدل لاتین bundled، بدون دانلود) | — |
| تحلیل هوشمند | استدلال مدل زبانی روی همه شواهد → ۳ کاندید مرتب‌شده | بله (سرویس بدون‌کلید) |
| تأیید پایگاه فیلم | بررسی هر کاندید در ویکی‌پدیا (انگلیسی + فارسی) → سال، کارگردان، توضیح، پوستر، لینک | بله |
| امتیازدهی ترکیبی | الگوریتم اختصاصی: تطبیق og-title / هشتگ / OCR با نام کاندید + تأیید ویکی‌پدیا → ٪اطمینان صادقانه | — |

## 🧠 الگوریتم شناسایی (خط‌لوله اختصاصی)

```
لینک اینستاگرام (خودکار از کلیپ‌بورد یا دستی)
   │
   ▼
۱. بررسی اتصال — چک خودکار اینستاگرام/اینترنت → وضعیت فیلترشکن
   │
   ▼
۲. خواندن پست — ۴ روش موازی روی دستگاه: صفحهٔ پست با UA موتور جستجو (og:title/og:description + آدرس mp4 امضاشده)،
   embed/captioned، ?__a=1 (X-IG-App-ID)، og: meta + رفع ریدایرکت /share/
   │
   ▼
۳. استخراج فریم — دانلود ویدیو به کش → MediaMetadataRetriever → ۳ فریم (۱۲٪/۴۵٪/۷۸٪ زمان)
   │
   ▼
۴. متن روی تصویر — ML Kit OCR (مدل لاتین bundled، بدون دانلود) → تیتراژ، زیرنویس، کارت عنوان
   │
   ▼
۵. تحلیل هوشمند — LLM بدون‌کلید: کپشن + هشتگ + og-title + OCR → حداکثر ۳ کاندید با دلیل فارسی
   │
   ▼
۶. تأیید — ویکی‌پدیا REST (بدون کلید): عنوان/سال/کارگردان/توضیح/پوستر + جستجوی عنوان فارسی
   │
   ▼
۷. امتیازدهی اختصاصی — تطبیق نرمال‌شدهٔ نام کاندید با og-title/هشتگ/OCR (+۰٫۱ تا +۰٫۱۵ هر کدام)
   + تأیید فیلم بودن در ویکی‌پدیا (+۰٫۲۵) → ٪اطمینان صادقانه؛ در حالت مرزی، پاس دوم LLM شواهد را تلفیق می‌کند
   │
   ▼
نتیجه: اسم فیلم (انگلیسی + فارسی) + سال + کارگردان + پوستر + ٪اطمینان + توضیح فارسی + گزینه‌های دیگر + لینک ویکی‌پدیا
```

> نسخهٔ وب همان خط‌لوله را با هوش مصنوعی بینایی قوی‌تر (z-ai SDK) و جستجوی وب ارائه می‌دهد.

## 🖥 نسخه وب

```bash
bun install
bun run db:push     # ساخت دیتابیس SQLite
bun run dev         # http://localhost:3000
```

وب‌اپ روی `/` اجرا می‌شود و همان ایده را با مدل بینایی قدرتمندتر و جستجوی وب ارائه می‌دهد:

- `POST /api/identify` — ورودی `{url}` یا `{imageBase64}` → پاسخ **SSE** با رویدادهای مرحله‌ای و نتیجهٔ نهایی
- `GET /api/history` — تاریخچه (۳۰ مورد آخر)
- `DELETE /api/history` — پاک‌سازی تاریخچه

> اپ اندروید **به این سرور وابسته نیست** — همه‌چیز را خودش انجام می‌دهد. نسخهٔ وب فقط یک رابط جایگزین با توان بیشتری است.

## 🛠 بیلد دستی APK

```bash
cd android-app
gradle assembleDebug          # خروجی: app/build/outputs/apk/debug/app-debug.apk
```

(یا پروژهٔ `android-app` را در Android Studio باز کن.)

پوشهٔ `.github/workflows/android-build.yml` روی هر push به `android-app/**` به‌صورت خودکار هر دو APK (debug و release) را می‌سازد و در GitHub Release منتشر می‌کند.

## 📂 ساختار

```
├─ src/                     نسخه وب Next.js (فارسی RTL + PWA)
│  ├─ app/api/identify/     خط‌لوله SSE شناسایی (مدل بینایی + جستجوی وب)
│  ├─ app/api/history/      تاریخچه
│  └─ lib/                  اسکرپر اینستاگرام + موتور شناسایی
├─ android-app/             اپ اندروید نیتیو (Kotlin + Compose) — موتور هوشمند روی دستگاه
│  └─ app/src/main/java/com/filmyab/app/
│     ├─ data/              SmartEngine (فریم+OCR+LLM+ویکی‌پدیا)، اسکرپر ۴روشه، تاریخچه محلی
│     └─ ui/                صفحات شناسایی / تاریخچه (بدون تنظیمات)
├─ prisma/schema.prisma     مدل دیتابیس نسخه وب
└─ .github/workflows/       بیلد خودکار APK
```
